PCSIP StoreFront: clinical application access in context

Clinicians should not have to spend valuable time opening multiple applications, searching for the same patient and rebuilding clinical context in every system.

How it works

Application access driven by identity, role and patient context

PCSIP StoreFront is designed to provide secure, context-aware access to clinical applications from within the PCSIP environment. Instead of treating application delivery as a separate step from clinical workflow, PCSIP can use the clinician’s identity, role, patient and care context to launch the systems required for the task at hand.

In radiation oncology, for example, Core Mobile’s architecture is designed so that a clinician working with a patient can access applications such as ARIA, Eclipse, CPRS and PACS within the appropriate patient context rather than manually moving between disconnected environments.
