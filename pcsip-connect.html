VA Technology Modernization

Modernizing healthcare interoperability: from interface engines to PCSIP Connect

Healthcare interoperability has evolved beyond simply moving HL7 messages between systems. PCSIP Connect brings integration, workflow orchestration, monitoring and modern interoperability services into the broader PCSIP platform.

The evolution

From NextGen Mirth Connect to a governed integration layer

Core Mobile’s earlier VA architecture used NextGen Mirth Connect as an integration server for connectivity with systems such as VistA. PCSIP’s newer interoperability architecture expands that model across legacy and modern systems.

Bidirectional data exchangeNormalization & mappingMessage routingTransformationInterface monitoringException handlingAPI-based integration
Why it matters

A governed integration layer, not a collection of interfaces

Instead of treating interoperability as a collection of individual interfaces, PCSIP Connect is designed to support a governed integration layer that can connect EHRs, specialty systems, devices, patient applications and operational platforms while creating data that is ready for analytics and AI.
