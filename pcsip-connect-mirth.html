What it does

Daily interface administration, without the desktop client

Browser administration

Manage channels, deployments, messages and settings from a browser. No desktop administrator client to install.

Familiar Mirth concepts

Channels, filters, transformers, the Config Map and the Message Browser work the way your team expects.

A staged transition

Import existing channel exports and move interfaces one at a time, with your current engine still running.

Migration process

Replace each interface only after it is accepted

  1. 01InventorySources, destinations, dependencies and priorities for every channel.
  2. 02Import and reviewImport channel exports. Imported channels stay disabled until reviewed.
  3. 03Test and reconcileRun both engines on equivalent test traffic and reconcile the results.
  4. 04Approved cutoverCut over channel by channel or in small groups, with rollback ready.
Your existing engine stays live until each replacement is tested and accepted.

AI and security

Optional AI access, governed like everything else

When you enable it, approved AI tools reach permitted interface data through an MCP (Model Context Protocol) gateway. Every request is permission-checked and logged. The interface engine does not depend on AI to process messages.
